🛒 Simple E‑Commerce Project
📖 Overview
A beginner‑friendly e‑commerce web app built with HTML, CSS, and JavaScript.
It allows users to:

View products

Add items to a shopping cart

Remove items from the cart

See the total price

Checkout (cart clears)

Cart data is saved in LocalStorage so it persists after refresh

🛠️ Technologies Used
HTML5 for structure

CSS3 for styling (dark theme, buttons, layout)

JavaScript (ES6) for cart logic and LocalStorage
